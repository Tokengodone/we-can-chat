# 快速使用指南

## 1. 安装依赖

```powershell
npm install
```

## 2. 启动应用

```powershell
npm run electron:dev
```

也可以使用 `npm run dev` 启动 Vite 开发模式；推荐使用 `electron:dev`，它明确以 Electron 模式启动桌面应用。

## 3. 连接微信数据

在欢迎页选择自己的微信数据目录。应用会在本地扫描账号目录并建立数据库连接。数据库解密密钥只应从数据所有者处获得，不要把它写进源码、命令历史、Issue 或日志。

## 4. 浏览与分析

- “聊天”：分页浏览、搜索和定位消息。
- “通讯录”：查看联系人和群成员。
- “聊天分析”：查看消息分布、活跃时间和成员统计。
- “年度报告”和“双人报告”：生成只读报告。
- “导出数据”：选择会话、时间范围、媒体选项和导出格式。
- “数据库备份”：创建和管理应用登记的备份。

## 5. 使用 AI

在设置中填写兼容 OpenAI API 的地址、模型和 API Key。只有启用相应功能后，聊天上下文才会发送到该服务。使用前请确认服务商的数据保留、训练和跨境处理政策。

## 6. 使用微信回复

微信回复仅支持 Windows。安装 Python 3.12 和依赖后，在“微信回复”页面：

1. 检测 Python、`wxauto4` 和微信客户端连接。
2. 绑定一个唯一的好友备注或群聊名称。
3. 先用“仅草稿”模式生成回复。
4. 使用测试消息验证目标是否正确。
5. 设置发送间隔、每小时上限、每日上限和安静时段。
6. 只有在确认风险后，才开启倒计时或全自动模式。

不要用于群发、营销、自动加好友或高频发送。微信窗口不可见、锁屏或版本更新时，自动化可能失败。

## 7. 本地 API

HTTP API 默认关闭，并且只监听 `127.0.0.1`。启用后请使用随机 Token，并避免把 Token 放在公开脚本、截图、Issue 或聊天记录中。接口细节见 [HTTP-API.md](HTTP-API.md)。

## 8. 发布前检查

```powershell
npm run typecheck
npm run build
```

发布前确认没有提交 `WeFlow-config.json`、`.env`、数据库、导出目录、日志、缓存或个人媒体文件。

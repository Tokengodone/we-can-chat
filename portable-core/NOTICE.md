# Attribution and use limits

This package extracts and adapts code from **WeFlow** by hicccc77.

The upstream source is licensed under **CC BY-NC-SA 4.0**. This extracted package therefore remains for non-commercial use, requires attribution, and must be shared under compatible terms when redistributed. See `LICENSE.upstream.txt` for the full license.

This package is intended to read and export data belonging to the user who runs it. It accepts a database key supplied by the caller; it does not obtain credentials from another process.

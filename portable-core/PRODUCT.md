# Product

## Register

product

## Users

People who need to inspect and export their own locally stored WeChat data from a focused desktop workflow, including users who are not comfortable operating command-line tools.

## Product Purpose

Provide a local interface for opening a WeChat 4.x account database with a user-supplied key, selecting conversations, exporting messages and media, and optionally converting voice messages to text. Success means the user can complete the workflow without exposing private data to an external service.

## Brand Personality

Calm, capable, and trustworthy. The product should feel like a focused desktop utility.

## Anti-references

Avoid decorative SaaS dashboards, oversized promotional typography, ambiguous custom controls, excessive cards, hidden data transfer, and technical language in the primary workflow.

## Design Principles

- Keep the path from database selection to export direct and visible.
- Make local processing and storage destinations explicit.
- Keep the database key in memory only and never display it after entry.
- Use familiar desktop controls and clear progress feedback.
- Preserve enough detail for users to understand failures and recover.

## Accessibility & Inclusion

Maintain keyboard access, visible focus and status feedback, readable contrast, descriptive labels, reduced-motion compatibility, and a layout that works from 1024 to 1920 pixels wide.
